# Better Server List

The multiplayer screen, organized. Keep your servers in several lists, sort them into collapsible categories, pin favorites to the top, and find any server by just typing. Drag and drop to sort, right-click for everything else.

![The server list with several lists, pinned servers and colored categories](https://wiki.mycelium-gg.org/betterserverlist/img/overview.png)

- Multiple lists: Favorites, Modded, Events, whatever you need
- Collapsible, colored categories inside each list
- Search by name, address, MOTD, note or category: just start typing
- Sort by your own order, name, players, ping or last played
- Online-only filter hides servers that don't answer
- Drag and drop to reorder, into a category or onto another list (hold Ctrl to copy)
- Notes on any server, plus when you last played and how often
- Copy a whole list as text and paste servers from the clipboard
- Keyboard shortcuts: arrows, Shift+arrows to move, Enter, Delete, F2, F5

![The right-click menu moving a server into another category](https://wiki.mycelium-gg.org/betterserverlist/img/context-menu.png)

Safe to try: your servers are imported on first start and the vanilla `servers.dat` stays in sync, so removing the mod loses nothing. The Vanilla button opens the original screen any time.

## Install

Client side: install it in your own game.

Requires [Mycel](https://www.curseforge.com/minecraft/mc-mods/mycel): install it alongside this mod. Minecraft 26.1, 26.2 and 26.3 on Fabric, Forge and NeoForge, Java 25. On Fabric you also need Fabric API.

Every setting and command is on the [wiki](https://wiki.mycelium-gg.org/betterserverlist/).
