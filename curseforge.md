# Better Server List

The multiplayer screen, organized. Keep your servers in several lists, sort
them into collapsible categories, pin favorites to the top, and find any
server by just typing. Drag and drop to sort, right-click for everything
else. Client side.

- **Multiple lists**: Favorites, Modded, Events, whatever you need
- **Categories**: collapsible, colored sections inside each list
- **Pin** servers to the top of their list
- **Search** by name, address, MOTD, note or category: just start typing
- **Sort** by your own order, name, players, ping or last played
- **Online only** filter hides servers that don't answer
- **Drag and drop** to reorder, into a category, or onto another list
  (hold Ctrl to copy)
- **Notes** on any server, plus when you last played and how often
- Right-click menus for servers, categories and lists
- Copy a whole list as text and paste servers from the clipboard
- LAN worlds, server icons, MOTDs, player lists and ping, like vanilla
- Keyboard shortcuts: arrows, Shift+arrows to move, Enter, Delete, F2, F5
- Your servers are imported on first start, and the vanilla `servers.dat`
  stays in sync, so removing the mod loses nothing
- *Vanilla* button opens the original screen any time
- Config: `enabled`, `replaceScreen`, `showLan`, `confirmDelete`
- Requires **Mycel**: install it alongside this mod

Reload live with `/mycel reload betterserverlist`.
Docs: https://wiki.mycelium-gg.org/betterserverlist/
