# Better Server List (NeoForge)

The multiplayer screen, organized: several server lists, collapsible
categories, pinned favorites, search, sorting and drag and drop.

- Lists, categories and pins; notes and play history per server
- Type to search; sort by name, players, ping or last played
- Imports your servers and keeps the vanilla list in sync

Requires **Mycel**. Needs NeoForge, Minecraft 26.3, 26.2 or 26.1.2, Java 25.
